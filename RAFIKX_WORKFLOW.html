RAFIKX

코딩을 몰라도 됩니다. 할 일을 말하면, 난이도를 나누고, 연결해 둔 모델과 계정 중에서 항로를 잡아 실행합니다. 리밋이 걸리면 다음 계정으로 스스로 갈아탑니다.

운영 흐름 보기 명령 한 줄
CONSTELLATION

한 사람이 쓰는 항해 시스템

클라우드 모델은 빌려 쓰고, 결정과 기억과 안전장치는 내 컴퓨터에 둡니다. 첫 연결은 번호만 고르면 됩니다.

번호로 연결

서비스·모델 이름을 외울 필요 없습니다. 키와 토큰만 붙여넣습니다.

자동 하네스

설계·검증·디버깅은 등록한 모델 중 추론이 센 쪽을 고릅니다.

계정 항로

같은 모델에 계정을 여러 개 두면, 리밋이 먼저 끝난 쪽을 쓰고 막히면 전환합니다.

침묵하는 문

텔레그램 허용 목록 밖에는 답하지 않습니다. 원격 무조건 승인은 코드가 막습니다.

MISSION CONTROL

실제 운영 항로

문서용 상자가 아니라, 오늘 한 번 일을 맡겼을 때 신호가 지나가는 길입니다. 재생을 누르면 한 미션이 처음부터 끝까지 흘러갑니다.

STANDBY
대기. 재생을 누르면 「hello.txt 만들어줘」 미션이 스테이션을 지나갑니다.
DAILY ORBIT

하루가 실제로 도는 방식

아침

연결을 연다

처음이면 OpenCode Zen·Go, Claude 등 하나를 고르고 키를 붙이거나 로그인합니다. 같은 서비스에 회사/개인 계정을 더 넣을 수 있습니다.

작업

한 줄로 맡긴다

짧은 질문은 quick, 설계는 thinker, 파일 수정은 coder. 자동이면 등록 모델 중 순위가 높은 쪽이 나갑니다.

장애

리밋을 피한다

429가 오면 그 계정은 쉬고, 리밋이 먼저 끝난 다른 계정으로 즉시 갈아탑니다. 화면 아래에 사용량이 보입니다.

밤

점검은 읽기만

Inspector가 요약을 만들 수 있지만 코드와 설정을 스스로 고치지 않습니다. 교훈은 다음 항해에만 실립니다.

NAVIGATION RULES

항법 규칙

워크스페이스 감옥

파일과 명령은 정해 둔 폴더 밖을 나가지 못합니다.

승인

로컬은 y/n/a. 텔레그램은 버튼. 시간 초과는 거부입니다.

원격 --yes 금지

폰에서 무조건 승인은 켜지지 않습니다.

비밀

키와 토큰은 secrets/auth에만 두고, 로그와 이 페이지에 원문을 남기지 않습니다.

INSTALL

한 줄로 설치

Windows와 macOS(그리고 Linux)는 같은 프로그램입니다. Rust가 없으면 스크립트가 같이 넣습니다.

환경한 줄
macOS / Linuxcurl -fsSL https://raw.githubusercontent.com/AIBeginnerX/RafikX/master/install.sh | bash
Windows PowerShellirm https://raw.githubusercontent.com/AIBeginnerX/RafikX/master/install.ps1 | iex

자세한 환경·문제 해결은 저장소의 docs/INSTALL.md 를 보세요. 저장소를 아직 공개하지 않았다면 로컬에서 cargo install --path agent-harness --force 입니다.
