# 성능 기준선 (2026-08-28 재측정, v1.0.1 + v5 전체 반영 후)

측정: macOS (Apple Silicon), release 빌드, `/usr/bin/time`. SPEC v3 표와 대조.

| 항목 | 합격선 | 도전 목표 | 실측 | 판정 |
| --- | --- | --- | --- | --- |
| 바이너리 (기본 빌드) | < 20MB | < 12MB | **7.2MB** | ✅ 도전 달성 |
| RAM — 단발 ask | < 30MB | < 15MB | **14.3MB** | ✅ 도전 달성 |
| Cold start | < 150ms | < 30ms | 완전 냉 610ms · 웜 ~0ms | ⚠️ 합격선 미달 (냉 시작) |
| FTS5 검색 | < 50ms | < 10ms | 50ms | ⚠️ 합격선 경계 |
| facts 조회/주입 | < 5ms (F1 목표) | < 3ms | ~0ms | ✅ 달성 |

## 해석

- 기능이 v5 기간에 약 2배(도구 15→24종, 모듈 84→96개) 늘었는데 바이너리와 RAM은 도전 목표를 유지했다.
- Cold start 610ms는 빌드 직후 첫 실행(dyld·페이지 캐시)에서만 관측되고 이후는 ~0ms다. macOS 캐시 재현 제약으로 매 회차 측정이 어려워, 개선 작업은 사용자 체감이 생길 때까지 보류한다 (SPEC 원칙: 합격선만 넘으면 다음 Phase — 정확히 미달인 이 항목만 추적 대상).
- FTS 50ms는 합격선 경계 — 노트 수가 늘면 재측정한다.
