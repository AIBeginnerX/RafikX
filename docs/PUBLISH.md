# 공개 전에 (관리자용)

아직 GitHub에 올리지 않았습니다. 올릴 준비가 되면 아래만 하면 됩니다.

1. GitHub에서 저장소 `rafikx` 를 만듭니다. 문서 기본값은 `AIBeginnerX/rafikx` 입니다. 계정/이름이 다르면 `install.sh`, `install.ps1`, README, docs의 주소를 바꿉니다.
2. 비밀 파일이 커밋에 없는지 확인합니다. (`.gitignore` 참고)
3. `git remote add origin https://github.com/AIBeginnerX/rafikx.git`
4. `git push -u origin master` (또는 `main` 이면 브랜치 이름과 문서의 `master` 를 맞춥니다)
5. About에 한 줄: `Personal AI coding agent for the terminal and Telegram.`
6. 랜딩 미리보기: `RAFIKX_WORKFLOW.html` 을 브라우저로 엽니다. GitHub Pages를 쓰려면 나중에 따로 정합니다.

올리지 말라고 하면 4번을 실행하지 마세요.
